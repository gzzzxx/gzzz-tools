## 📖 简介

**gzzz-tools** 收录了日常开发中最常用的 **16 个在线工具**，覆盖 **加密 / 开发 / 转换 / 时间** 四大类。

所有工具都在浏览器本地运行，**输入的数据不会上传到任何服务器** —— 密钥、密文、待格式化的 SQL / JSON 全部留在你自己的设备上。

## ✨ 特性

- 🔒 **隐私优先**：纯前端运算，数据零上传
- 🌍 **中英双语**：随时切换，选择会被记住
- 🎨 **明亮 / 暗黑主题**：一键切换，带扩散过渡动画
- ⭐ **收藏工具**：把常用工具钉在首页，支持拖拽排序
- 🔍 **全局搜索**：`Ctrl / Command + K` 快速找到任意工具
- 📱 **全端适配**：电脑、平板、手机都能用
- ⚡ **打开即用**：静态托管，无需注册登录

## 🚀 快速开始

```bash
git clone https://github.com/gzzzxx/gzzz-tools.git   # 或 gitee.com/gzzzxx/gzzz-tools
cd gzzz-tools
npm install
npm run dev        # http://localhost:1000
```

需要 **Node.js 18+**。其它命令：

| 命令 | 作用 |
| --- | --- |
| `npm run dev` | 本地开发 |
| `npm run build` | 构建产物到 `dist/` |
| `npm run generate` | 静态预渲染（部署用，产物同样是 `dist/`） |
| `npm run typecheck` | 类型检查 |
